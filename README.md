# Seoyeongari wetland model

This repository contains the reproducibility package linked from the paper's Data Availability statement.

## Model status

The central paper result is the **no-groundwater-exchange run** (`Cgw = 0 d-1`). The explicit groundwater term is retained only as a structural sensitivity analysis for Supplementary Section S.4; `Cgw > 0` is not a calibrated central-model parameter.

The daily water-balance notation used in the manuscript is:

\[
\Delta W = 10^{-3}\{A_P(P_P-E_{P,\mathrm{eff}}-Q_P-Q_S)+A_C R+A_T(P_T-ET_T)\}.
\]

Here precipitation, evapotranspiration, and recession terms are water depths in mm d-1, while the area terms are in m2. `Q_P` is the pond recession loss and `Q_S` is the excess-storage/spill term in the manuscript notation. The implementation stores the corresponding daily losses and fluxes in m3 d-1 after multiplying by area and dividing by 1000.

## Central reproduction result (`Cgw = 0`)

The script scores the six independent mapped-area years 2013, 2015, 2017, 2019, 2021, and 2023. The representative prediction is the ensemble median for each year. nRMSE is RMSE divided by the mean observed area over those six years, multiplied by 100.

| Scenario | RMSE (m2) | nRMSE (%) |
|---|---:|---:|
| Baseline | 164.1231 | 8.0410 |
| Eco–Geo | 44.9467 | 2.2021 |
| Hydrosere | 131.2404 | 6.4300 |
| Integrated | 38.2614 | 1.8746 |

The Integrated 2023 prediction is 1950.7021 m2 (residual +68.0021 m2). The maximum daily mass-balance residual in the central run is below 4e-13 m3.

The complete central output snapshot is in `RESULTS/`. The file `RESULTS/stage239_explicit_gw_scores.csv` contains all four scenarios for `Cgw = 0` and the positive-coefficient sensitivity values generated by the same executable.

## Main equations and parameters

- External contributing area: 8483 m2; NRCS-CN = 68; external throughfall fraction = 0.70.
- Pond area used by the rasterized model: 2241.7624 m2.
- Pond/wetland throughfall: 100%; herb and forest throughfall: 70% (30% interception).
- Pond evaporation is calculated as `EP`; the state-weighted effective pond loss is `fw * (F_TRAPA*EP + F_SCHOENO*0.80*EP)`, with `F_TRAPA` and `F_SCHOENO` derived from the mapped Trapa and Schoenoplectiella areas.
- Rain-free recession: `R_DRY = 0.0114 m d-1`, applied only when daily precipitation is zero.
- ET multipliers: forest 1.00, exposed herb 0.90, exposed bare 0.30, flooded sedge 0.80 of pond evaporation.
- Dry exposure/reflood gate: 14 days and 0.05 m reflood depth.
- Peat input: 0.8022 kg m-2 yr-1; organic-matter bulk density: 171.48 kg m-3; decay rate `K0 = 0.25 yr-1`; decay exponent 0.55.
- DSM shape scale: sigma = 0.065 m; combined tree-ring case; simulation period: 2011–2024, with scoring through 2023.

## Repository layout

- `CODE/stage239_explicit_gw_exchange.py`: central four-scenario run and Apr–May groundwater sensitivity sweep.
- `CODE/stage239_explicit_gw_exchange_c015_four.py`: four-scenario `Cgw = 0.015 d-1` sensitivity.
- `CODE/stage239_monthly_gw_exchange_integrated.py`: Integrated monthly-boundary sensitivity.
- `CODE/stage239_monthly_gw_exchange_integrated_high.py`: higher-coefficient monthly sensitivity.
- `DATA/`: only the meteorological and spatial files read by the scripts.
- `GROUNDWATER_INPUT/`: extracted monthly head series used to document the S.4 groundwater boundary; the central `Cgw=0` result does not depend on it.
- `RESULTS/`: central rerun outputs; `RESULTS/SI/` contains positive-`Cgw` sensitivity snapshots.

The manuscript PDF and earlier development files are intentionally not included.

## Reproduction

From the repository root:

```bash
python -m pip install -r requirements.txt
python CODE/stage239_explicit_gw_exchange.py
```

The run creates `GW_EXCHANGE_RESULTS/` and writes the same CSV tables listed in `RESULTS/`. Required Python packages are listed in `requirements.txt`: NumPy, pandas, GeoPandas, Shapely, Rasterio, Fiona, and PyProj.
